## 0. 表结构变更（实现前置条件，必须先执行）

当前 `user_db` 只有 `user_id / user_name / user_age / user_img / user_note` 五列，**无法支撑注册与登录**（无密码字段、姓名可重复）。实现业务 1/2 前需执行以下 DDL：

```sql
ALTER TABLE `user_db`
  ADD COLUMN `user_password` VARCHAR(100) NOT NULL DEFAULT '' COMMENT '登录密码，存 BCrypt 哈希（60 字符），禁止明文',
  ADD COLUMN `created_at`    DATETIME(3)  NOT NULL DEFAULT CURRENT_TIMESTAMP(3) COMMENT '注册时间',
  ADD COLUMN `updated_at`    DATETIME(3)  NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3) COMMENT '更新时间',
  ADD COLUMN `is_deleted`    TINYINT(1)   NOT NULL DEFAULT 0 COMMENT '逻辑删除：0正常 1已删',
  ADD COLUMN `status`        TINYINT      NOT NULL DEFAULT 1 COMMENT '账号状态：1启用 0禁用',
  ADD KEY `idx_created_at` (`created_at`);

-- 注册要求 user_name 唯一：原普通索引升级为唯一索引
-- 注意：如现存数据有重名，需先去重再执行
ALTER TABLE `user_db` DROP INDEX `idx_user_name`, ADD UNIQUE KEY `uk_user_name` (`user_name`);
```

变更后完整字段：

| 字段 | 类型 | 说明 | 注册/登录是否使用 |
| --- | --- | --- | --- |
| `user_id` | BIGINT UNSIGNED PK | 主键自增 | 返参 |
| `user_name` | VARCHAR(50) **UNIQUE** | 账号/姓名，注册后不可改 | 入参 + 返参 |
| `user_password` | VARCHAR(100) NOT NULL | BCrypt 哈希，**任何接口不回传** | 入参（仅注册/登录） |
| `user_age` | TINYINT UNSIGNED | 0-150 | 入参（可选） |
| `user_img` | LONGBLOB | 头像 | 不涉及（沿用现有头像接口） |
| `user_note` | LONGTEXT | 备注 | 入参（可选） |
| `created_at` | DATETIME(3) | 注册时间 | 报表返参 |
| `updated_at` | DATETIME(3) | 更新时间 | — |
| `is_deleted` | TINYINT(1) | 逻辑删除 | 报表过滤 `= 0` |
| `status` | TINYINT | 1 启用 / 0 禁用；禁用账号不能登录 | 登录校验 |

> 依赖新增：`spring-security-crypto`（仅取 BCrypt 工具类，不引入整套 Spring Security）、`jjwt-api/impl/jackson 0.12.x`（登录签发 JWT）。

## 1. 业务 1：用户注册

### 1.1 业务流程

```
客户端                     user-service                    MySQL
  │  POST /auth/register      │                             │
  │──────────────────────────>│ 1. 参数校验（JSR-303）        │
  │                           │ 2. SELECT 查 user_name 重复  │
  │                           │────────────────────────────>│
  │                           │ 3. BCrypt.hashpw(password)   │
  │                           │ 4. INSERT user_db            │
  │                           │────────────────────────────>│
  │  200 {code:0, data:{...}} │                             │
  │<──────────────────────────│                             │
```

规则：

1. `user_name` 全库唯一（唯一索引兜底；应用层先查再插，捕获 `DuplicateKeyException` 仍返回 40901）。
2. 密码**必须 BCrypt 加密后入库**，数据库与日志中永不出现明文与哈希。
3. 注册成功自动登录的方案**暂不采用**，注册后由客户端跳转登录页调业务 2。
4. 并发重名兜底：唯一索引 `uk_user_name` 兜住竞态，冲突统一映射为 40901。

### 1.2 接口文档

| 项 | 值 |
| --- | --- |
| 接口地址 | `/api/v1/auth/register` |
| 请求方法 | `POST` |
| Content-Type | `application/json` |
| 鉴权 | 无需（公开接口） |

**入参**（Request Body）

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
| --- | --- | --- | --- | --- |
| `userName` | String | 是 | 2–50 字符；仅限中文、字母、数字、`_`；全库唯一 | 账号/姓名 |
| `password` | String | 是 | 8–32 位；须同时包含字母与数字；允许 `!@#$%^&*_.+-` | 登录密码（明文传输，依赖 HTTPS） |
| `userAge` | Integer | 否 | 0–150 | 年龄 |
| `userNote` | String | 否 | ≤ 500 字符 | 备注 |

**返参**（`data`）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `userId` | Long | 新用户 ID |
| `userName` | String | 账号 |
| `createdAt` | String (yyyy-MM-dd HH:mm:ss) | 注册时间 |

**成功示例**

```json
// 请求
{"userName": "zhangsan", "password": "abc12345", "userAge": 30, "userNote": "备注😀"}

// 响应 HTTP 200
{
  "code": 0,
  "message": "success",
  "data": {"userId": 1, "userName": "zhangsan", "createdAt": "2026-11-10 01:40:00"},
  "traceId": "a1b2c3d4"
}
```

**错误返参**（HTTP 状态码一律 200，业务错误靠 `code` 区分，见 02 文档规范）

| code | message | 触发场景 |
| --- | --- | --- |
| 40001 | 缺少必填参数：userName / password | 字段缺失 |
| 40002 | 参数格式错误：userName 仅限中文、字母、数字、下划线 | 用户名含非法字符 |
| 40002 | 参数格式错误：password 须 8–32 位且包含字母和数字 | 密码不符合复杂度 |
| 40003 | 参数超出允许范围：userAge 须在 0-150 | 年龄越界 |
| 40901 | 用户名已被注册 | `user_name` 唯一冲突 |
| 50000 | 服务内部错误 | 数据库异常等 |

```json
// 错误示例：用户名已存在
{"code": 40901, "message": "用户名已被注册", "data": null, "traceId": "a1b2c3d4"}
```

## 2. 业务 2：用户登录

### 2.1 业务流程

```
客户端                     user-service                    MySQL
  │  POST /auth/login         │                             │
  │──────────────────────────>│ 1. 参数校验                  │
  │                           │ 2. 按 user_name 查用户        │
  │                           │────────────────────────────>│
  │                           │ 3. status=0? → 40302 拒绝     │
  │                           │ 4. BCrypt.checkpw 比对密码     │
  │                           │ 5. 签发 JWT（HS256，2h）       │
  │  200 {code:0, token:...}  │                             │
  │<──────────────────────────│                             │
```

规则：

1. 密码校验用 `BCrypt.checkpw`，**先查无此用户与密码错误的对外提示一致**（均为 40101「用户名或密码错误」），防止账号枚举。
2. 登录凭证采用 **JWT（HS256）**，payload 含 `userId / userName / exp`，有效期 **2 小时**；签名密钥放 `.env`（`JWT_SECRET`），禁止入库入仓。刷新 token 机制列入二期，不在本文范围。
3. `status = 0`（禁用）的账号直接拒绝，错误码 40302，且**提示语不区分禁用与密码错误**以外的细节。
4. 登录失败不写失败次数锁定（一期不做），列入二期风控增强。

### 2.2 接口文档

| 项 | 值 |
| --- | --- |
| 接口地址 | `/api/v1/auth/login` |
| 请求方法 | `POST` |
| Content-Type | `application/json` |
| 鉴权 | 无需（公开接口） |

**入参**（Request Body）

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
| --- | --- | --- | --- | --- |
| `userName` | String | 是 | 2–50 字符 | 账号 |
| `password` | String | 是 | 8–32 位 | 登录密码 |

**返参**（`data`）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `token` | String | JWT，后续请求放 `Authorization: Bearer <token>` |
| `expiresIn` | Long | 有效期秒数，固定 `7200` |
| `userId` | Long | 用户 ID |
| `userName` | String | 账号 |

**成功示例**

```json
// 请求
{"userName": "zhangsan", "password": "abc12345"}

// 响应 HTTP 200
{
  "code": 0,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9.eyJ1c2VySWQiOjF9.xxxx",
    "expiresIn": 7200,
    "userId": 1,
    "userName": "zhangsan"
  },
  "traceId": "a1b2c3d4"
}
```

**错误返参**

| code | message | 触发场景 |
| --- | --- | --- |
| 40001 | 缺少必填参数：userName / password | 字段缺失 |
| 40101 | 用户名或密码错误 | 用户不存在 **或** 密码不匹配（统一提示） |
| 40302 | 账号已被禁用，请联系管理员 | `status = 0` |
| 50000 | 服务内部错误 | 数据库异常等 |

```json
// 错误示例：密码错误
{"code": 40101, "message": "用户名或密码错误", "data": null, "traceId": "a1b2c3d4"}
```

> 网关侧约定（随登录一并实现）：除 `/api/v1/auth/**` 外，所有路由要求携带合法 JWT，缺失/过期/签名不符返回 `code: 40100, message: "未登录或凭证无效"`。

## 3. 业务 3：报表 - 查询注册人员

### 3.1 业务流程

查询**已注册**（未逻辑删除）的用户列表，附统计摘要。数据口径：

- 只统计 `is_deleted = 0` 的记录；
- 「今日新增」按 `created_at` 落在当天 `[00:00, 24:00)` 计算（服务器东八区）；
- `user_password / user_img` 不在列表返参中返回（脱敏 + 避免大字段拖垮列表）。

### 3.2 接口文档

| 项 | 值 |
| --- | --- |
| 接口地址 | `/api/v1/report/users` |
| 请求方法 | `GET` |
| Content-Type | — |
| 鉴权 | 需要 JWT（`Authorization: Bearer <token>`） |

**入参**（Query String，全部可选）

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
| --- | --- | --- | --- | --- |
| `pageNum` | Integer | 否 | ≥ 1，默认 1 | 页码 |
| `pageSize` | Integer | 否 | 1–100，默认 10 | 每页条数，上限 100 |
| `userName` | String | 否 | ≤ 50 字符 | 按账号模糊搜索（LIKE %x%） |
| `startDate` | String | 否 | yyyy-MM-dd | 注册时间起（含） |
| `endDate` | String | 否 | yyyy-MM-dd | 注册时间止（含） |

**返参**（`data`）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `summary.total` | Long | 注册总人数（不含已删） |
| `summary.todayCount` | Long | 今日新增人数 |
| `summary.disabledCount` | Long | 被禁用账号数 |
| `list[].userId` | Long | 用户 ID |
| `list[].userName` | String | 账号 |
| `list[].userAge` | Integer | 年龄（可为 null） |
| `list[].status` | Integer | 1 启用 / 0 禁用 |
| `list[].createdAt` | String | 注册时间 yyyy-MM-dd HH:mm:ss |
| `pageNum / pageSize / total / pages` | — | 分页元信息（同 02 文档 PageResult 结构） |

**成功示例**

```json
// 请求
GET /api/v1/report/users?pageNum=1&pageSize=10&userName=张

// 响应 HTTP 200
{
  "code": 0,
  "message": "success",
  "data": {
    "summary": {"total": 26, "todayCount": 3, "disabledCount": 1},
    "list": [
      {"userId": 1, "userName": "张三", "userAge": 31, "status": 1, "createdAt": "2026-11-09 22:10:33"}
    ],
    "pageNum": 1, "pageSize": 10, "total": 1, "pages": 1
  },
  "traceId": "a1b2c3d4"
}
```

**错误返参**

| code | message | 触发场景 |
| --- | --- | --- |
| 40100 | 未登录或凭证无效 | 未携带 / 过期 / 签名非法的 JWT |
| 40002 | 参数格式错误：日期格式须为 yyyy-MM-dd | startDate/endDate 非法 |
| 40003 | 参数超出允许范围：pageSize 须在 1-100 | 分页参数越界 |
| 50000 | 服务内部错误 | 数据库异常等 |

```json
// 错误示例：未登录
{"code": 40100, "message": "未登录或凭证无效", "data": null, "traceId": "a1b2c3d4"}
```

## 4. 错误码汇总（本文件新增部分）

| code | 枚举建议 | message | 使用接口 |
| --- | --- | --- | --- |
| 40901 | `USERNAME_TAKEN` | 用户名已被注册 | 注册 |
| 40101 | `LOGIN_FAILED` | 用户名或密码错误 | 登录 |
| 40302 | `ACCOUNT_DISABLED` | 账号已被禁用，请联系管理员 | 登录 |
| 40100 | `UNAUTHORIZED`（已有） | 未登录或凭证无效 | 报表 / 网关全局 |

> 实现时把前三个追加进 `gyy-common` 的 `ErrorCode` 枚举；同时按 02 文档流程把三个接口同步进 Apifox（springdoc 注解自动导出 `/v3/api-docs`）。
